# Security

Fertile Grounds is a small farming mod, but mods run on players' computers and servers, so safety matters. Thanks for looking out for everyone!

## Which versions get fixes

| Version | Minecraft | Gets security fixes? |
|---|---|---|
| 2.0 | 26.1, 26.2, 26.3 | Yes |
| 1.2.0 and older | 1.21.11 and older | No, please update to 2.0 on Minecraft 26.1 or newer |

## Found a problem?

Please tell us privately first, so it can be fixed before anyone uses it to cause trouble.

1. Open the [Security tab](https://github.com/Adi-UA/fertile-grounds/security) and click **Report a vulnerability**. Only the maintainer can see your report.
2. If you don't see that button, message [@Adi-UA](https://github.com/Adi-UA) on GitHub and say you found a security problem, without the details. We'll find a private way to talk.

Please don't post the details in a public issue, discussion, or pull request.

## What to include

- The mod version and Minecraft version, like `2.0.0+26.3`
- What happens, and what someone could do with it (crash a server, change other players' worlds, and so on)
- Steps to make it happen, if you have them

## What happens next

The maintainer reads every report and replies as soon as they can. Once it's fixed, the fix ships in a new release and the release notes thank you, unless you'd rather stay anonymous.

Bugs that aren't about safety, like a crop growing wrong or a crash in single player, can go straight to a normal [issue](https://github.com/Adi-UA/fertile-grounds/issues/new/choose).
